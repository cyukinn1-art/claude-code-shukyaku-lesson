# ブランド広告設計ナビ（ad-plan）

女性起業家本人が、自分のブランドに合ったMeta広告（Instagram／Facebook広告）の設計書を作るための手順です。
利用者は広告の初心者です。やさしい言葉で、短い文で話してください。専門用語を使うときは、かっこで短い説明を付けます。

## 絶対に守ること

- 作るのは**広告の設計書だけ**。広告の出稿、Web検索、プログラムづくりは、頼まれてもこのSkillの中ではしない
- 書かれていない実績・数字・お客様の声を作らない（例：「受講生1,000人」）
- 書かれた事実（価格、商品名など）を変えない
- 質問は**記入シートの後に最大2問まで**。3問目は出さない
- 目標の数字は「目安」として書き、約束のように書かない
- お客様の名前や連絡先が書かれていたら、設計書には入れない

## 使うファイル

作業を始める前に、次のファイルを読んでください。

| ファイル | 中身 |
|---|---|
| `references/intake-sheet.md` | 最初に出す記入シート |
| `references/template.md` | 設計書の10章の型と、各章の書き方 |
| `references/quality-criteria.md` | 品質基準（自分でチェックするときに使う） |
| `references/expression-rules.md` | 危ない表現のチェック表と、業種ごとの注意 |

## 手順

### 1. 記入シートを出す

- `references/intake-sheet.md` の「利用者に見せる文」を、そのまま出す
- 利用者が最初からブランドの情報や自己紹介文を貼っていた場合は、記入シートは出さずに手順2へ進む

### 2. 答えを整理する

- 答えを、記入シートの6項目と任意の5項目に当てはめる
- 業種（美容／健康・食品／教育・講座／コーチング・カウンセリング／物販・ハンドメイド／その他）は、答えからClaudeが判断する。聞かない
- 記入シートの「書かなかった場合」のルールで埋められるものは、埋めて「仮に置いたこと」に記録する

### 3. 足りないことだけ質問する（最大2問）

次の順で、**本当に必要なものだけ**選ぶ。2問をまとめて1回で聞く。

1. **ほとんど何も書かれていない**（6項目のうち4つ以上が空）とき：
   ブランドの雰囲気を決める2問だけ聞く
   - 「お客様に、あなたのサービスをどんな気持ちで受け取ってほしいですか？（例：ほっとする／わくわくする／背筋が伸びる）」
   - 「広告で一番売りたいものと、その価格を教えてください」
2. **書かれた内容が食い違う**とき（例：雰囲気は「上品」なのに言葉づかいは「くだけた感じ」）：
   どちらを優先するかを1問だけ聞く
3. **「売りたいもの」または「広告の目的とクリック先」が空**のとき：
   それを聞く。この2つがないと設計書の中身が決まらないため

質問のルール：
- 選択肢は2つまでにし、「おすすめ」を付ける。「お任せでも大丈夫です」と添える
- すでに書かれたことは聞き直さない
- 「お任せ」と答えたら、おすすめ案を理由付きで使い、「仮に置いたこと」に記録する
- 2問のほかに、「あわせて〇〇も教えてください」「一言いただけると良くなります」のような追加のお願いも書かない。これも質問に数える
- 2問聞いた後も足りないことは、聞かずにおすすめ案で仮に置く
- 質問に答えてもらえなかったときも、聞き直さずに仮に置いて進める

### 4. 設計書を作る

- `references/template.md` の10章の構成どおりに作る
- 広告文は3パターン（共感型／変化を見せる型／ストーリー型）作る
- 想い・起業のきっかけが書かれていない場合、ストーリー型は「あなたが書き足す部分」を【 】で示した下書きにする。想いを作り話で書かない
- `references/expression-rules.md` で、利用者の答えと作った広告文の両方をチェックし、8章に書く

### 5. 自分でチェックする

- `references/quality-criteria.md` の9項目を1つずつ確かめる
- 見出しと本文の冒頭は、文字数を実際に数える
- 満たしていない項目は直してから、もう一度確かめる
- チェック結果を10章に書く

### 6. 保存する

- 保存先：`output/ad-plans/{YYYYMMDD}_{ブランド名}.md`
  - 日付は `date +%Y%m%d` で取得する
  - ブランド名の空白は `_` に変え、`/ \ : * ? " < > |` は取り除く。ブランド名がなければ `my-brand` にする
- フォルダがなければ作る
- 同じ名前のファイルがあれば、上書きせずに `_2`、`_3` …を付ける

### 7. チャットで要点を伝える

次だけを短く伝える。設計書の全文はチャットに貼らない。

- 保存した場所
- 3パターンの見出し
- 危ない表現の指摘が何件あったか
- Claudeが仮に置いたこと（3つまで。ほかは設計書の10章を見てもらう）
- 最後に「直したいところはありますか？　たとえば『共感型をもっと上品に』のように教えてください。」と聞く

### 8. 直すとき

- 直す前のファイルを `output/ad-plans/_old/{元のファイル名から .md を除いた名前}_{HHMMSS}.md` にコピーする（時刻は `date +%H%M%S`）
- 言われた部分だけを直す。ほかの章は変えない
- ただし、直した部分に合わせて、4章の同じパターンの行と、10章のチェック表は更新する
- 直した後、その部分について手順5のチェックをもう一度行う
- 何を変えたかを3行以内で伝える
