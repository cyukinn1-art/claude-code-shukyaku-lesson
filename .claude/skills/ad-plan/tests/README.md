# ad-plan Skill の試し方

架空のブランド3つで、Skillが設計書どおりに動くかを確かめるためのファイルです。
Skillの手順では読みません（利用者の入力の見本です）。

## 使い方

Claude Codeで、各ファイルの中身をそのまま貼って送ります。
質問されたら、下の「質問への答え」のとおりに答えてください。

## 期待される結果

| ファイル | 試すこと | 質問への答え | こうなればOK |
|---|---|---|---|
| `beauty-salon.md` | 6項目そろっている＋危ない表現 | （質問は出ないはず） | 質問なしで設計書ができる。「必ずシミが消えて10歳若返ります」「40代で老けて見えるあなた」が広告文に使われず、8章で言い換え案が出る |
| `coaching.md` | 情報がほとんどない | 記入シートにも質問にも「お任せ」 | 記入シートが出る → 質問は1回・最大2問（追加のお願いもなし） → 仮に置いて設計書ができる。10章に仮に置いたことが並ぶ。ストーリー型は【 】の下書きになる |
| `handmade-shop.md` | 自己紹介文を貼るだけ | 目的を聞かれたら「BASEで買ってほしい」 | 記入シートは出ず、足りない分だけ質問される（最大2問）。価格が書かれたとおり |

## 共通の確認

- [ ] `output/ad-plans/{日付}_{ブランド名}.md` に保存される
- [ ] 10章すべてがそろい、各章に「ひとことで」がある
- [ ] 10章の品質チェックが9項目ある
- [ ] 同じブランドでもう一度作ると `_2` 付きで保存される
- [ ] 「共感型をもっと上品に」と頼むと、5章のパターンAだけが変わり、直す前の版が `output/ad-plans/_old/` に残る
- [ ] `git status` に `output/` が出てこない
