# 記入シート

## 利用者に見せる文

以下を、そのまま利用者に出してください。

---

広告設計書を作りますね。
まず、分かるところだけ教えてください。全部そろっていなくても大丈夫です。
自己紹介文や、販売ページ（LP）の文章を貼っていただくだけでもOKです。

**必ず書いてほしいこと（6つ）**

1. 広告で売りたいもの（名前と価格）
   例：90分の体験レッスン 3,000円
2. 理想のお客様
   例：40〜50代、仕事も家事も頑張っている女性
3. お客様の悩み・叶えたいこと
   例：忙しくて自分のケアができない
4. あなたの強み・選ばれる理由
   例：元エステティシャン歴15年
5. 広告の目的と、広告を押した人に行ってほしい場所
   例：LINEに登録してほしい
6. 1か月の広告予算
   例：30,000円

**書けたら書いてほしいこと**

- 屋号・ブランド名
- ブランドの雰囲気（例：上品、やさしい、元気）と、言葉づかい（丁寧／親しみ）
- 起業のきっかけ・想い
- 広告を出したい地域
- 使いたくない言葉

※お客様の名前や連絡先は書かないでください。

---

## 書かなかった場合のルール

| 書かれていないこと | どうするか |
|---|---|
| 屋号・ブランド名 | 設計書では「あなたのブランド」と書く。ファイル名は `my-brand` |
| ブランドの雰囲気 | 答えの内容からClaudeが3つ提案し、仮に置く |
| 言葉づかい | 「丁寧」で仮に置く |
| 起業のきっかけ・想い | ストーリー型の広告文を、【 】に書き足す形の下書きにする |
| 地域 | 「全国（来店型のお店なら、お店から通える範囲）」で仮に置く |
| 使いたくない言葉 | なし |
| 広告予算 | 「1か月30,000円」で仮に置く |
| 理想のお客様／悩み／強み | ほかの答えから推測して仮に置く。推測であることを「仮に置いたこと」に書く |

## 広告の目的とクリック先の対応

利用者の言葉を、次のどれかに当てはめてください。

| 利用者の言葉の例 | 広告の目的 | クリック先 |
|---|---|---|
| LINEに登録してほしい | 見込みのお客様を集める | LINE公式アカウント |
| 体験に申し込んでほしい | 申し込みを増やす | 申し込みページ（LP） |
| 商品を買ってほしい | 売上を増やす | ネットショップ |
| まずは知ってほしい | 知ってもらう | Instagramのプロフィール |
| フォロワーを増やしたい | 知ってもらう | Instagramのプロフィール |
