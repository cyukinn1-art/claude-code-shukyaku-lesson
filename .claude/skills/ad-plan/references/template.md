# 広告設計書の型

この型の見出し（1〜10章）は、変えずに使ってください。
`<!-- -->` の中は書き方の説明です。設計書には残さないでください。

各章の最初に「**ひとことで**：」を1行入れてください。
一文は短く（目安60字まで）。専門用語には、かっこで短い説明を付けます。

---

```markdown

## 4. 伝え方の軸（3パターン）

**ひとことで**：同じ商品を、3つの違う切り口で伝えて、どれが反応がよいか比べます。

| パターン | 切り口 | このパターンで伝えたいこと |

<!--
- 3パターンの中身は、はっきり変える。同じ文の言い換えにしない。
- 想い・起業のきっかけが書かれていない場合、Cは【ここに、あなたが起業したきっかけを1文で】のように、書き足す部分を【 】で示す。作り話はしない。

-->

## 7. クリック先との確認

**ひとことで**：広告で約束したことが、押した先の最初に書かれているかを確かめます。

- [ ] 広告の見出しで約束したことが、{クリック先}の最初の画面に書かれている
- [ ] 価格・内容が、広告とクリック先で同じ
- [ ] 広告の雰囲気と、クリック先の雰囲気がそろっている
- [ ] {クリック先に合わせた確認を1〜2つ。例：LINE登録後すぐに届くメッセージが用意されている}

## 9. うまくいかないときの直し方

**ひとことで**：

| こんなとき | まず直すところ |
|---|---|
| 広告が見られているのに、押されない（クリック率が低い） | 画像と見出し |
| 押されているのに、登録・申し込みがない | クリック先（7章の確認） |
| そもそも広告があまり表示されない | 予算と、届ける相手の設定（狭すぎないか） |
| 1件あたりの費用が高い | 反応のよいパターンに予算を寄せる |
```
