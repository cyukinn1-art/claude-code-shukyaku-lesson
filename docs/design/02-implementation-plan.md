# 実装計画：ブランド広告設計ナビ（Claude Code版）

> **ひとことで**：Skillのファイルを作る → 架空のブランド3つで試す → あなたが試して直す、の3段階で進めます。
>
> 状態：**計画のみ**。「実装を開始して」と言われるまで、作り始めません。
> 設計書：`01-ad-plan-skill.md`

---

## 1. 進める順番

```
Step 1  Skillのファイルを作る
   ↓
Step 2  架空のブランド3つで試して、直す（Claudeが行う）
   ↓
Step 3  あなたが実際に使ってみて、直す
```

## 2. できあがるファイル

```
claude-code-shukyaku-lesson/
├─ .claude/skills/ad-plan/
│   ├─ SKILL.md                    … 手順と質問のルール（入口）
│   └─ references/
│       ├─ intake-sheet.md         … 最初に出す記入シート
│       ├─ template.md             … 設計書の10章の型
│       ├─ quality-criteria.md     … 品質基準
│       ├─ expression-rules.md     … 危ない表現のチェック表（業種ごとの注意つき）
│       └─ samples/                … 試す用の架空のブランド3つ
│           ├─ beauty-salon.md     … 美容サロン（わざと危ない表現を入れる）
│           ├─ coaching.md         … コーチング（情報少なめ）
│           └─ handmade-shop.md    … ハンドメイド（自己紹介文を貼るだけの形）
├─ output/ad-plans/                … 作った設計書の保存先（GitHubに上げない）
└─ .gitignore                      … output/ を除外
```

## 3. Stepごとの作業

### Step 1：Skillのファイルを作る

| No | 作業 | できたかの確認 |
|---|---|---|
| 1-1 | `SKILL.md`：使うタイミング（「広告設計書を作って」など）と手順を書く | 設計書の「6. 使う流れ」と同じになっている |
| 1-2 | `intake-sheet.md`：記入シートを書く | 必ず書く項目が6つ、任意が5つ |
| 1-3 | `template.md`：設計書の10章の型を書く | 設計書の「9」と同じ |
| 1-4 | `quality-criteria.md`：品質基準を書く | 設計書の「10」の9項目と同じ |
| 1-5 | `expression-rules.md`：危ない表現と言い換え例を書く | 6種類それぞれに、例と言い換えがある |
| 1-6 | `samples/`：架空のブランドを3つ作る | 美容サロンには危ない表現が入っている |
| 1-7 | `.gitignore` に `output/` を追加 | `git status` に出ない |

### Step 2：架空のブランドで試す（Claudeが行う）

| No | 作業 | できたかの確認 |
|---|---|---|
| 2-1 | 3つのブランドで、設計書の「16. テスト」の8つを試す | 8つすべてOK |

| 2-3 | うまくいかなかった点を直し、もう一度試す | 直した内容を記録する |

### Step 3：あなたが使ってみる

| No | 作業 | 担当 |

| 3-1 | 架空のブランドの設計書3つを読む | あなた |

| 3-3 | 「質問がわかりにくい」「広告文の雰囲気が違う」などを伝える | あなた |
| 3-4 | 言われた点を直す | Claude |
