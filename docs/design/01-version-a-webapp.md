# ツール設計書【A版】Webアプリ版 ブランド広告設計ナビ

> 共通部分（入力項目・出力の中身・品質基準・表現チェック）は `00-common-ad-plan.md` を参照してください。
> ステータス：**設計中（初稿）**。実装はまだ始めていません。

---

## 1. 概要

女性起業家（受講生など）がブラウザでブランド情報を入力し、「広告設計書を作る」ボタンを押すと、AI（Claude）が広告設計書を作って画面に表示するWebアプリです。

- 最小構成：**1画面**（入力 → 作成 → 結果）、ログインなし、データ保存なし
- 利用を受講生に限るため、**合言葉（パスコード）** を入れた人だけが使えるようにする

## 6. 利用の流れ

**初回**
1. 利用者が、あなたから受け取ったURLを開く
2. 合言葉を入力する（ブラウザに記憶され、次回からは入力不要）
3. 入力フォームに、ブランド情報を入力する
4. 「広告設計書を作る」ボタンを押す
5. 作成中の表示が出て、できた部分から文章が順番に表示される（目安30〜90秒）
6. 完成した設計書を「コピー」または「ダウンロード（.md）」する

**2回目以降**
- 前回の入力内容がブラウザに下書きとして残っているので、直して再作成できる

**入力不足の場合**
- ボタンを押した時点で、未入力の必須項目の近くに赤字でエラーを表示し、作成は始めない

**処理に失敗した場合**
- 入力内容は消さずに、「もう一度作る」ボタンを表示する

## 7. 画面と操作

### 画面0：合言葉入力（初回のみ）
- 表示：ツール名、説明1行、合言葉の入力欄、「はじめる」ボタン
- 間違えた場合：「合言葉が違います」と表示。5回続けて間違えたら10分間入力できない

### 画面1：メイン画面（入力・結果）

**上部：入力フォーム**（3つのまとまりに分ける）
- ① あなたのブランド（共通編の入力項目 No.1〜10、17）
- ② 広告の目的（No.11〜14）
- ③ 補足（任意）（No.15〜16）
- 各項目に、短い記入例を薄い文字で表示
- 必須項目には「必須」マーク
- 注意書き：「お客様の名前や連絡先は入力しないでください。入力内容はAIに送信されます。」

**ボタン**
| ボタン | 押した後の動作 |
|---|---|
| 広告設計書を作る | 必須項目をチェック → 問題なければ作成開始。作成中はボタンを押せなくし、「作成中…」と表示 |
| 入力をクリア | 確認ダイアログを出し、「はい」で入力と下書きを消す |
| 作成を止める | 作成中だけ表示。押すと作成を中止し、それまでの内容を残す |

**下部：結果表示**
- 広告設計書を見出し付きで表示
- 「コピー」ボタン：押すと「コピーしました」と2秒表示
- 「ダウンロード」ボタン：`広告設計書_{ブランド名}_{日付}.md` を保存
- 「もう一度作る」ボタン：同じ入力で作り直す

**スマートフォン**
- 入力欄は縦1列で並べる。横スクロールは出さない
- 「広告設計書を作る」ボタンは画面下に固定表示

## 8. 機能要件

### 機能1：合言葉チェック
- 目的：受講生以外の利用で、AI利用料が増えるのを防ぐ
- 処理：サーバー側で合言葉を照合（合言葉は環境変数に保存し、コードには書かない）
- 完成確認：正しい合言葉で入れる／違う合言葉で入れない

### 機能2：入力チェック
- 必須項目が空、文字数オーバー、予算が数字でない場合はエラーを表示
- チェックは画面とサーバーの両方で行う

### 機能3：広告設計書の作成
- 入力：共通編の入力項目
- 処理：サーバーからClaude APIへ、入力内容と「設計書の型・品質基準・表現チェック基準」をまとめて送る
- 出力：共通編の構成どおりのMarkdown。できた部分から順に画面へ表示（ストリーミング）
- 保存：しない
- 回数制限：1人（1つのブラウザ）あたり1日10回まで（仮定）

### 機能4：下書きの自動保存
- 入力内容を、利用者のブラウザ内（localStorage）だけに保存
- サーバーには保存しない

### 機能5：コピー・ダウンロード
- 結果をワンクリックでコピー、.mdファイルで保存

## 11. 外部サービス連携

| 項目 | 内容 |
|---|---|
| サービス名 | Claude API（Anthropic） |
| 目的 | 広告設計書の文章を作る |
| 送信する情報 | 利用者の入力内容、設計書の型、品質基準 |
| 受け取る情報 | 広告設計書の文章 |
| 認証 | APIキー（サーバーの環境変数に保存。ブラウザには渡さない） |
| 失敗した場合 | 「混み合っています。少し待ってからもう一度お試しください」と表示し、入力は残す |
| 利用料金 | 使った文字量に応じて1回ごとに発生。実装前に最新の料金表で1回あたりの費用を試算する |
| 代替手段 | 停止中はB版（Claude Code版）を使う |

## 12. 利用者と権限

| 利用者 | できること |
|---|---|
| 受講生 | 合言葉を入れて、設計書を作る。自分のブラウザ内の下書きだけ見られる |
| 管理者（あなた） | 合言葉の変更、APIキーの管理、利用料の確認（Anthropicの管理画面で行う） |

- 他人の入力内容は、サーバーに保存しないため見られない

## 13. エラーと例外

| エラー | 表示 | 入力を残す | 再試行 |
|---|---|:---:|:---:|
| 必須項目が空 | 該当欄の下に「入力してください」 | ○ | ○ |
| 文字数オーバー | 「〇字以内で入力してください（現在〇字）」 | ○ | ○ |
| ボタンの連打 | 作成中はボタンを押せない | ○ | — |
| 通信に失敗 | 「通信に失敗しました。もう一度お試しください」 | ○ | ○ |
| AIが混雑・停止 | 「混み合っています。少し待ってからお試しください」 | ○ | ○ |
| AIの結果が空・途中で切れた | 「うまく作成できませんでした。もう一度お試しください」 | ○ | ○ |
| 1日の回数上限 | 「本日の作成回数の上限に達しました。明日またご利用ください」 | ○ | × |
| 作成中に再読み込み | 作成は中止。入力は下書きから復元 | ○ | ○ |
| 合言葉の期限切れ・変更 | 合言葉の画面に戻る | ○ | ○ |

- サーバーには、エラーの種類と時刻だけ記録する（入力内容は記録しない）

## 14. 非機能要件

- パソコン・スマートフォン（幅375px以上）で使える
- 対応ブラウザ：Chrome、Safari、Edgeの最新版
- 作成時間：最初の文字が10秒以内に表示され始める（目標）
- 月額運用費：サーバーは無料枠内、AI利用料は月数千円以内を目安（仮定。上限は未決事項）
- APIキーと合言葉はコードに書かない

## 15. 技術構成案

| 技術 | 役割 | 理由 |
|---|---|---|
| Next.js（React） | 画面とサーバー処理を1つにまとめる | 画面とAPI呼び出しを1つのプロジェクトで作れる。情報が多く、Claude Codeが実装しやすい |
| Vercel | 公開（ホスティング） | GitHubとつなぐだけで公開できる。小規模なら無料枠で運用できる |
| Claude API（Sonnet 5.5） | 設計書の作成 | 文章の質と費用のバランスがよい。質を最優先するならOpus 5.5に切り替え可能 |
| Tailwind CSS | 見た目 | スマートフォン対応を素早く作れる |

- 初期費用：0円（ドメインを使う場合は別途）
- 月額費用：Vercel無料枠＋AI利用料（使った分だけ）
- 別案：Googleフォーム＋自動化サービス → 結果が見づらく、待ち時間の表示ができないため不採用
- 将来の注意：利用者が増えたら、合言葉からログイン方式へ切り替えを検討

## 16. 完成条件

- [ ] 正しい合言葉で画面1に入れる。違う合言葉では入れない
- [ ] 必須項目をすべて入力して実行すると、共通編の構成（1〜10章）どおりの設計書が表示される
- [ ] 必須項目が空の場合は作成を始めず、該当欄の近くにエラーを表示する
- [ ] 作成中は「広告設計書を作る」ボタンを二重に押せない
- [ ] 作成に失敗しても入力内容は消えず、「もう一度作る」で再試行できる
- [ ] 結果をワンクリックでコピーでき、.mdファイルでダウンロードできる
- [ ] ブラウザを閉じて開き直しても、入力内容が下書きとして残っている
- [ ] スマートフォン幅（375px）で横スクロールが発生しない
- [ ] APIキーがブラウザ側のコードや通信内容に含まれていない
- [ ] 共通編の「出力の品質基準」を、テスト用の入力3件ですべて満たす
- [ ] 本番用ビルドがエラーなく完了し、自動テストがすべて成功する

## 17. テストケース

| テスト名 | 事前条件 | 操作・入力 | 期待される結果 | 確認方法 |
|---|---|---|---|---|
| 正常：美容サロン | 合言葉入力済み | 美容業種で必須項目をすべて入力し実行 | 10章構成の設計書が表示され、3パターンのコピーがある | 画面確認＋自動テスト（AIは模擬応答） |
| 正常：コーチング | 同上 | 任意項目なしで実行 | 設計書が表示され、「10. 仮定したこと」に不足分が書かれている | 画面確認 |
| 品質：NG表現 | 同上 | 強みに「必ず痩せる」と入力 | 設計書の「8. 表現の注意点」で指摘され、コピーには使われない | 実際のAIで手動確認 |
| 異常：必須項目が空 | 同上 | ブランド名を空にして実行 | 作成が始まらず、ブランド名欄にエラー表示 | 自動テスト |
| 異常：文字数オーバー | 同上 | 事業内容に301字入力 | 文字数エラーが表示される | 自動テスト |
| 異常：連打 | 同上 | ボタンを素早く3回押す | 作成は1回だけ行われる | 自動テスト |
| エラー：AI停止 | AIが失敗を返す設定 | 実行 | エラー文が出て、入力が残り、再試行できる | 自動テスト（模擬エラー） |
| エラー：回数上限 | 当日10回作成済み | 実行 | 上限メッセージが表示される | 自動テスト |
| 権限：合言葉なし | 未入力 | URLを直接開く／サーバーへ直接送信 | 画面0に戻る／サーバーは拒否する | 自動テスト |
| 表示：スマホ | — | 幅375pxで表示 | 横スクロールなし、ボタンが下に固定 | Playwrightで画面確認 |

## 18. 仮定（A版）

- 利用者は受講生数十名で、合言葉を1つ共有する
- 1人1日10回までの作成制限を設ける
- AIモデルはSonnet 5.5を使う
- 公開先はVercelの無料枠とする
